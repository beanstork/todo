# To-Do App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a personal AI-powered to-do list web app deployed on GitHub Pages at beanstork.github.io/todo/ with Supabase persistence and Claude-powered natural language task parsing.

**Architecture:** Single `index.html` on GitHub Pages (no build step). A Cloudflare Worker proxies Claude API calls, keeping the API key server-side. The browser reads/writes Supabase directly using the anon key.

**Tech Stack:** Vanilla JS + HTML + CSS (single file), Supabase JS client v2 (CDN), Cloudflare Workers, Claude claude-sonnet-4-20250514, Web Speech API, Google Fonts (DM Serif Display + DM Sans).

## Task 1: Cloudflare Worker

**Files:**
- Create: `worker.js`
- Deploy: Cloudflare dashboard (not in repo deploy pipeline)

- [ ] **Step 1: Create `worker.js` with this exact content:**

```js
export default {
  async fetch(request, env) {
    const corsHeaders = {
      'Access-Control-Allow-Origin': 'https://beanstork.github.io',
      'Access-Control-Allow-Methods': 'POST, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type',
    };

    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: corsHeaders });
    }

    if (request.method !== 'POST') {
      return new Response('Method not allowed', { status: 405 });
    }

    try {
      const { text, today } = await request.json();

      const systemPrompt = `You are a task parser. Given natural language input, return ONLY valid JSON — no markdown, no explanation.

Categories: personal, finance, admin, projects, mishmish, social
Priority: urgent, high, normal
Today: ${today}

Return exactly:
{
  "text": "clean task description",
  "category": "personal|finance|admin|projects|mishmish|social",
  "priority": "urgent|high|normal",
  "emoji": "single relevant emoji or null",
  "due": "YYYY-MM-DD or null",
  "notes": "extra context or null"
}

Rules:
- mishmish is the user's cat — anything about Mishmish goes in mishmish category
- urgent = needs doing today or ASAP
- high = deadline within a week
- Resolve relative dates (next Tuesday, end of month, in 3 days) to absolute YYYY-MM-DD based on today
- Pick a relevant emoji that adds meaning, or null if nothing fits`;

      const response = await fetch('https://api.anthropic.com/v1/messages', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'x-api-key': env.ANTHROPIC_API_KEY,
          'anthropic-version': '2023-06-01',
        },
        body: JSON.stringify({
          model: 'claude-sonnet-4-20250514',
          max_tokens: 500,
          system: systemPrompt,
          messages: [{ role: 'user', content: text }],
        }),
      });

      const data = await response.json();
      return new Response(JSON.stringify(data), {
        headers: { 'Content-Type': 'application/json', ...corsHeaders },
      });
    } catch (e) {
      return new Response(JSON.stringify({ error: e.message }), {
        status: 500,
        headers: { 'Content-Type': 'application/json', ...corsHeaders },
      });
    }
  },
};
```

- [ ] **Step 2: Deploy the Worker to Cloudflare**

  1. Go to https://dash.cloudflare.com → **Workers & Pages** → **Create application** → **Create Worker**
  2. Name it `todo-api`, click **Deploy** (ignore the default code for now)
  3. In the Worker dashboard, click **Edit code**, paste the entire `worker.js` content above, click **Deploy**
  4. Go to **Settings** → **Variables and Secrets** → **Add** → Secret name: `ANTHROPIC_API_KEY`, value: your Anthropic API key → **Save**
  5. Note the Worker URL shown at the top — it will look like: `https://todo-api.YOURNAME.workers.dev`

- [ ] **Step 3: Test the Worker with curl (replace URL with yours)**

```bash
curl -X POST https://todo-api.YOURNAME.workers.dev \
  -H "Content-Type: application/json" \
  -d '{"text":"call the vet about Mishmish booster next Tuesday","today":"2026-05-09"}'
```

Expected: JSON response with `content[0].text` containing a JSON string like `{"text":"Call the vet about Mishmish booster","category":"mishmish","priority":"normal","emoji":"🐱","due":"2026-05-12","notes":null}`


```js
// === DATE UTILS ===
function getDaysUntil(dateStr) {
  if (!dateStr) return null;
  const due = new Date(dateStr + 'T00:00:00');
  const now = new Date();
  now.setHours(0, 0, 0, 0);
  return Math.round((due - now) / 86400000);
}

function formatDue(dateStr) {
  if (!dateStr) return null;
  const days = getDaysUntil(dateStr);
  if (days < 0) return { text: `Overdue by ${Math.abs(days)}d`, cls: 'overdue' };
  if (days === 0) return { text: 'Due today', cls: 'soon' };
  if (days === 1) return { text: 'Due tomorrow', cls: 'soon' };
  if (days <= 5) return { text: `Due in ${days}d`, cls: 'soon' };
  const d = new Date(dateStr + 'T00:00:00');
  return { text: `Due ${d.toLocaleDateString('en-GB', { day: 'numeric', month: 'short' })}`, cls: '' };
}

function isUrgent(task) {
  if (task.priority === 'urgent') return true;
  const d = getDaysUntil(task.due);
  return d !== null && d < 0;
}

function isHigh(task) {
  if (task.priority === 'high') return true;
  const d = getDaysUntil(task.due);
  return d !== null && d >= 0 && d <= 5 && !isUrgent(task);
}

function sortTasks(arr) {
  return [...arr].sort((a, b) => {
    const da = getDaysUntil(a.due);
    const db2 = getDaysUntil(b.due);
    const aOver = da !== null && da < 0;
    const bOver = db2 !== null && db2 < 0;
    if (aOver && !bOver) return -1;
    if (!aOver && bOver) return 1;
    if (aOver && bOver) return da - db2;
    if (da !== null && db2 !== null) return da - db2;
    if (da !== null) return -1;
    if (db2 !== null) return 1;
    const po = { urgent: 0, high: 1, normal: 2 };
    return (po[a.priority] || 2) - (po[b.priority] || 2);
  });
}

function esc(s) {
  return String(s || '').replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
}
```

```js
  const SpeechRec = window.SpeechRecognition || window.webkitSpeechRecognition;
  if (!SpeechRec) {
    setStatus('Voice input not supported in this browser');
    setTimeout(clearStatus, 3000);
    return;
  }
  recognition = new SpeechRec();
  recognition.continuous = false;
  recognition.interimResults = true;
  recognition.lang = 'en-US';

  recognition.onstart = () => {
    isListening = true;
    document.getElementById('micBtn').classList.add('listening');
    setStatus('🎤 Listening... (tap mic again to stop)');
  };

  recognition.onresult = (event) => {
    let transcript = '';
    for (let i = event.resultIndex; i < event.results.length; i++) {
      transcript += event.results[i][0].transcript;
    }
    document.getElementById('taskInput').value = transcript;
  };

  recognition.onend = () => {
    isListening = false;
    document.getElementById('micBtn').classList.remove('listening');
    setStatus('');
    recognition = null;
  };

  recognition.onerror = (e) => {
    isListening = false;
    document.getElementById('micBtn').classList.remove('listening');
    const msg = e.error === 'not-allowed'
      ? 'Microphone access denied — check browser permissions'
      : 'Voice input error: ' + e.error;
    setStatus(msg);
    setTimeout(clearStatus, 4000);
    recognition = null;
  };

  recognition.start();
}

function stopListening() {
  if (recognition) recognition.stop();
}
```

```js
// === CALENDAR ===
function renderCalendar() {
  const grid = document.getElementById('calendarGrid');
  const year = calendarDate.getFullYear();
  const month = calendarDate.getMonth();
  const today = new Date();
  today.setHours(0, 0, 0, 0);

  const monthName = calendarDate.toLocaleDateString('en-GB', { month: 'long', year: 'numeric' });
  const firstDay = new Date(year, month, 1);
  const lastDay = new Date(year, month + 1, 0);
  const startDow = (firstDay.getDay() + 6) % 7; // Monday-first

  // Build tasksByDate map
  const tasksByDate = {};
  tasks.forEach(t => {
    if (t.due) {
      if (!tasksByDate[t.due]) tasksByDate[t.due] = [];
      tasksByDate[t.due].push(t);
    }
  });

  const dayLabels = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat', 'Sun'];

  let html = `
    <div class="calendar-nav">
      <button onclick="calPrev()">‹</button>
      <span class="calendar-month">${monthName}</span>
      <button onclick="calNext()">›</button>
    </div>
    <div class="calendar-grid">
      ${dayLabels.map(d => `<div class="calendar-day-header">${d}</div>`).join('')}`;

  // Blank cells before month start
  for (let i = 0; i < startDow; i++) {
    html += `<div class="calendar-day other-month"></div>`;
  }

  for (let d = 1; d <= lastDay.getDate(); d++) {
    const dateStr = `${year}-${String(month + 1).padStart(2, '0')}-${String(d).padStart(2, '0')}`;
    const dayDate = new Date(year, month, d);
    const isToday = dayDate.getTime() === today.getTime();
    const dayTasks = tasksByDate[dateStr] || [];
    const hasOverdue = dayDate < today && dayTasks.length > 0;
    const isSelected = selectedCalendarDay === dateStr;

    const cls = [
      'calendar-day',
      isToday ? 'today' : '',
      isSelected ? 'selected' : '',
    ].filter(Boolean).join(' ');

    const dot = dayTasks.length
      ? `<div class="day-dot${hasOverdue ? ' urgent' : ''}"></div>`
      : '';

    html += `<div class="${cls}" onclick="selectCalDay('${dateStr}')">
      <span class="day-num">${d}</span>
      ${dot}
    </div>`;
  }

  // Pad remaining cells
  const total = startDow + lastDay.getDate();
  const rem = total % 7;
  if (rem > 0) {
    for (let i = 0; i < 7 - rem; i++) {
      html += `<div class="calendar-day other-month"></div>`;
    }
  }

  html += `</div>`;
  grid.innerHTML = html;

  renderCalendarPanel(tasksByDate);
}

function selectCalDay(dateStr) {
  selectedCalendarDay = selectedCalendarDay === dateStr ? null : dateStr;
  renderCalendar();
}

function renderCalendarPanel(tasksByDate) {
  const panel = document.getElementById('calendarDayPanel');
  if (!selectedCalendarDay) { panel.innerHTML = ''; return; }

  const dayTasks = tasksByDate[selectedCalendarDay] || [];
  const d = new Date(selectedCalendarDay + 'T00:00:00');
  const label = d.toLocaleDateString('en-GB', { weekday: 'long', day: 'numeric', month: 'long' });

  panel.innerHTML = `
    <div class="calendar-panel">
      <div class="calendar-panel-title">${label}</div>
      ${dayTasks.length
        ? dayTasks.map(t => `
            <div class="task-item ${isUrgent(t) ? 'is-urgent' : isHigh(t) ? 'is-high' : ''}" style="margin-bottom:6px;cursor:default">
              <div class="task-body" style="cursor:default">
                <div class="task-text">${t.emoji ? esc(t.emoji) + ' ' : ''}${esc(t.text)}</div>
                ${t.priority && t.priority !== 'normal'
                  ? `<div class="task-meta"><span class="priority-badge p-${t.priority}">${t.priority}</span></div>`
                  : ''}
              </div>
            </div>`).join('')
        : `<p style="color:var(--text-faint);font-size:13px;font-style:italic">No tasks due this day</p>`
      }
    </div>`;
}

function calPrev() {
  calendarDate = new Date(calendarDate.getFullYear(), calendarDate.getMonth() - 1, 1);
  selectedCalendarDay = null;
  renderCalendar();
}

function calNext() {
  calendarDate = new Date(calendarDate.getFullYear(), calendarDate.getMonth() + 1, 1);
  selectedCalendarDay = null;
  renderCalendar();
}
```
